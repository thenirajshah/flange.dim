FLANGEREF — UPDATED WEBSITE

Files:
- index.html   Main website page
- style.css    Dark charcoal / lime-green design
- app.js       Parameter selectors and dimension rendering
- data.js      Bundled data used by the page (works when opened locally)
- data.json    Original structured data reference

HOW TO USE
1. Keep index.html, style.css, app.js and data.js in the same folder.
2. Open index.html in a browser, or upload all files to the same website directory.
3. Select a nominal pipe size, then choose Class 150 or Class 300.
4. Choose a flange type to filter the displayed dimension cards.

The Search Dimensions field has been removed. The original 42 dimension records
(21 for Class 150 and 21 for Class 300) are retained in data.json and bundled
into data.js so the size selector works without a local web server.

NOTE
This is a quick-reference viewer based on the supplied source data. Verify
critical design, fabrication and procurement values against the governing
controlled standard and project documentation.
